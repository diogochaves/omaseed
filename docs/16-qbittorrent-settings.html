qBittorrent's settings, inside omaseed

The goal: you never open qBittorrent's web UI for day-to-day settings. Today omaseed changes only the global speed limits. Everything else (DHT, the port, seeding rules, queueing, folders) still means a trip to the web UI. This board proposes where those settings live, how a change reaches the server, and every row in every section, named with the real qBittorrent 5.2.3 keys read from the :8081 playground.

The screenshots in §1 are the real main build, taken in an omabox. Everything after them is a mock in the v2 kit. The rows show the playground's current values.

2 · Where they live

A second group in Settings, named after the server

A (recommended): Settings gets a second group under omaseed's own: qBittorrent · playground, with seven sections. It edits the server omaseed is connected to. With more than one server, the group head names the server and s switches it. ctrl+, still opens Settings. ctrl+shift+, opens it straight on the qBittorrent group. When the window is narrow, the Q3 fold applies: the tabs row starts with a two-way switch, "omaseed · qBittorrent", and the tabs follow the group.

B: a separate "qBittorrent settings" sheet, opened from ⋯ and from each server's row in Settings › Servers. It keeps Settings short but gives you two places to look. C: each row in Settings › Servers opens into that server's settings. That's natural for many servers, but it hides the settings two levels down.

A. Settings at 1920 × 1080, on Discovery and privacy. The nav's second group carries the server's name and version.

5 · For private trackers

Three small helpers, outside Settings

A private torrent never uses DHT, PeX or LSD, whatever Discovery says: the torrent carries a private flag and qBittorrent obeys it. What private trackers do watch is anonymous mode, a reachable port and the client version. These three helpers make those visible where you already look.
