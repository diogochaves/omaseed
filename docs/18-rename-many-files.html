Rename many files at once

Today the Files tab renames one file at a time: r, type, enter, next row. That is fine for a typo and slow for an album, a season or a photo dump whose names all share a pattern. This board proposes one sheet that renames the selected files with a find and a replace, shows every new name before anything changes, and refuses to run while two names would collide.

The API has no batch call: each file is one torrents/renameFile, so the app sends them in order and stops at the first refusal. qBittorrent's dialog is read for behaviour only; nothing is copied from it.

How it behaves

  • What it renames. The selected files; with nothing selected, every file the Files tab shows (so the filter narrows it: / .flac, then r). Folders keep their one-at-a-time r.
  • Find. Plain text by default. The regex chip (ctrl+e) switches to a regular expression; $1, $2 in the replacement are its groups. Without "every match" only the first match in each name changes. Matching ignores case unless "match case" is on.
  • Name or extension. By default only the part before the last dot is searched, as the inline editor selects it. "Name and extension" searches the whole file name.
  • Counter. {n} in the replacement numbers the changing files in the order the tab lists them: {n} 1, 2…; {nn} 01, 02…; {nnn} 001.
  • Preview. Every selected file, old name dim, new name bright with the replaced part tinted. Unchanged files say so in dim text. The head counts what changes.
  • Collisions. Two new names that are the same, or a new name that another file in the folder already has, turn red, and the button reads 2 names collide and does nothing. An invalid regex shows its error in place of the preview.
  • Running it. enter (or the button) sends the renames one by one. The sheet closes when all are done. If qBittorrent refuses one, it stops there and says renamed 9 of 14 · 10 - Café Terrace.flac: refused (…); the files already renamed stay renamed.
  • Undo. None. The preview is the safety net, as it is in qBittorrent's dialog.
