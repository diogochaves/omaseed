# Manual test: what v0.4.0 adds

The person's pass before v0.4.0 is tagged. Only what the automated layer can't judge: whether it
reads well, looks right and feels right, on a real window. Everything else was checked by tests
and walks on the same commit (listed at the end, so you don't repeat it). About 20 minutes.

## Setup

```sh
scripts/dev/manual-box.sh          # a throwaway desktop, a window on workspace 9, omaseed from main
```

In the box: click into the window, **SUPER+ALT+ESC** (SUPER keys go to the box; again to give them
back), **SUPER+SPACE**, `omaseed`. First run finds "public" on `127.0.0.1:8090`; both logins are in
the box's `~/qbittorrent-login.txt` (also printed by `manual-box.sh`). Let first run register the
links (its "links" step): step 7 opens a magnet. "private" (`127.0.0.1:8091`) is already
downloading four small torrents; they finish in a minute or two.

## Steps

Each: what to do, then what you should see. Note OK, or what you saw instead.

1. **A server that isn't there (#122, #126).** Settings › Servers, **a**. Address
   `127.0.0.1:9`, test. A notice band (red, board 35's) under the form says it is
   "unreachable", not a one-line error. Change it to `127.0.0.1:8091` with private's login,
   test, add. Switch to it.
2. **Search by words (#125).** In the filter: `nested library`, then `recordings 3`, then
   `field.recordings`. Each finds its torrent, whatever the dots and the word order.
3. **The Status column (#74).** Table view, all four of private's torrents: each Status cell's
   glyph and word line up with the others, no row 4 px to the left. Quit and start omaseed
   twice more and look again.
4. **Skipped files that still hold space (#118, #160).** In the Files tab **x** skips or keeps
   the file under the cursor (**space** only marks it). Skip a small file first: Nested Library
   Sampler, a `still_…png`, **x**. An "On disk" column shows what it still holds and the footer
   says "1 skipped hold …"; no band, since the yellow band waits for 1 GiB or 5 % of the
   torrent. Now Field Recordings Vol. 3, cursor on "09 - Snowfall (Muffled).flac" (10 MB, about
   10 % of the album), **x**. The yellow band at the foot of the Files tab: "1 skipped file holds
   10 MB on …" (about), with "Free the space…" and "Why?". **?**: the help sheet lists **F** free the
   space. **:** (the command palette): type `free`, it offers "free the space…"; **esc**.
   **shift+f** (or the band's button): a sheet titled "Free …" says what is deleted; confirm.
   The band is gone and the file reads nothing on disk. Judge: do the band, "Why?" and the sheet
   read clearly?
5. **The 3 s hold (#119).** Same torrent, **x** on the Snowfall track again (no file skipped is
   the whole torrent wanted, so it waits). A band says what waits, its line running down over
   3 s, with Undo **u** and Send now **⏎**. **u**: the track is skipped again and nothing
   downloads. **x** again and leave it: after 3 s it downloads. Judge: is 3 s long enough to
   catch a misclick, and short enough not to annoy?
6. **Mouse picks and the outcome strip (#130).** **ctrl+click** two rows, **shift+click** a
   third: each picked row shows a filled box, and the bar's hint says how. **m**,
   `/home/sbx/Downloads/moved`, enter. A strip in the selection bar's place: "✓ … moved to …",
   its line running down over about 6 s; the rows read "✓ moved · moved" as long. Judge: is
   6 s enough to read it?
7. **Extras in the add sheet (#63).** Switch to public. In Files (Nautilus) or Chromium in the
   box, open `~/Downloads/links.html` and click the Public Domain Sampler magnet. Once its
   metadata is in, README.txt has a dim "extra" on its row, still ticked, and a dim line under
   the tree says "1 extra: a text file (…). Ticked, so the torrent seeds whole." Judge: is that
   sentence clear, and is the sheet still a good width?

When you're done: `scripts/dev/manual-box.sh down`.

## Not in this pass

These were checked by tests and walks on the same commit; their shots are in each walk's OUT
folder.

- **ntfs3, exfat and vfat (#120, #159):** the drive lines, the FAT32 4 GiB rule, a tick held
  because it doesn't fit. A box can't mount those disks, so the live tests run through the app
  on a loop image, and the QML tests check the lines. **No one has seen these lines in a real
  window yet.** If you have such a drive, check them on your own desktop once 0.4.0 is
  installed: open a torrent that saves there.
- **The stuck move's recheck (#158) and "finished, but still in the incomplete folder"
  (#121):** stuck-walk, on a full loop disk.
- **"replace it" (#176):** move-walk's big step.
- **"isn't answering" for a timeout (#122):** servers-walk.
- **A servers.json from an engines build (#178):** checked in a box with a Transmission server.
- **Screen readers (#91):** the accessibility tree in a box. **--help without a display
  (#143):** ctest.
- **Moves as a whole:** [moves.md](moves.md), unchanged since v0.3.
